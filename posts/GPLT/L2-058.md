## 思路
知识点：

map内部自动排序

auto it=mp.upper_bound(x)是二分查找函数，返回第一个大于x的迭代器（好像是这么叫的，不重要，重要的是用auto接收）

先用map处理输入，这样就不用再次排序了，如果是相同数值，只要存最小下标（在顺序处理输入时相当于不用操作）

输入的同时顺便记录最大值，开一个数组把最大值的下标存一下

查找时用upper_bound函数会方便得多，注意写法，像it==mp.end()和it->second（箭头是指向map的value的意思）这种直接背

## 代码
```c++
#include<bits/stdc++.h>
using namespace std;
int main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int n;cin>>n;
	map<int,int>mp;
	int maxnum=-1;
	vector<int>ID;
	for(int i=1;i<=n;i++){
		int t;cin>>t;
		if(!mp.count(t))mp[t]=i;//便于查找 
		//存最大ID 
		if(maxnum<t){
			ID.clear();
			ID.push_back(i);
			maxnum=t;
		}
		else if(maxnum==t)ID.push_back(i);
	}
	//最大 
	for(int i=0;i<ID.size();i++){
		if(i)cout<<" ";
		cout<<ID[i];
	}
	cout<<'\n';
	//查找 
	int k;cin>>k;
	while(k--){
		int t;cin>>t;
		auto it=mp.upper_bound(t);
		if(it==mp.end())cout<<0<<'\n';
		else cout<<it->second<<'\n';
	}
	return 0;
}
```
