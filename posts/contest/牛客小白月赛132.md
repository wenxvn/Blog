## 代码
```c++
#include<bits/stdc++.h>
using namespace std;
int n;
int cnt[7];

		else if(sum>=2800)cnt[6]++;
	}
	for(int i=0;i<7;i++)cout<<cnt[i]<<" ";
	return 0;
}
```



# 出题需要语文

## 思路

我第一反应是哈希表

可以用一个哈希表来存题目，定义为unordered_map<char,pair<int,int>>map

char中存ABCDEF，键值对的first存题目质量，second存题目编号

注意，遍历哈希表输出不能用auto &t:map，因为unordered_map只能存储数值，不能排序

用<char,pair<int,int>>来定义哈希表时，如何读取其中数值？

法一：用char c。map中的key用map[c]来表示,value用map[c].first和map[c].second来表示

法二：用auto &t:map。map中的key用t.first来表示,value用t.second.first和t.second.second来表示

## 代码
```c++
#include<bits/stdc++.h>
using namespace std;
int n;
int main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	unordered_map<char,pair<int,int>>map;
	for(char i='A';i<='F';i++)map[i]={0,-1};
	char c;
	int k;
	cin>>n;
	for(int i=1;i<=n;i++){
		cin>>c>>k;
		if(k>=60&&map[c].first<k)map[c]={k,i};
	}
	int sum=0;
	for(char c='A';c<='F';c++){
		if(map[c].second==-1){
			cout<<-1;
			return 0;
		}
		sum+=map[c].first;
	}
	if(sum<420)cout<<-1;
	else {
		for(char c='A';c<='F';c++){
			cout<<map[c].second<<" ";
		}
	}
	return 0;
}
```

## 优化思路
一共就ABCDEF这几道题目，哈希表有点麻烦，可以用普通的数组来存

开两个数组，一个存最大质量，一个存最大质量的题目的编号

## 最优解
```c++

#include<bits/stdc++.h>
using namespace std;
int n;
int best[6];
int id[6];
int main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	cin>>n;
	char c;
	int k;
	for(int i=1;i<=n;i++){
		cin>>c>>k;
		if(k>=60&&best[c-'A']<k){
			best[c-'A']=k;
			id[c-'A']=i;
		}
	}
	int sum=0;
	for(int i=0;i<6;i++){
		if(id[i]==0){
			cout<<-1;
			return 0;
		}
		sum+=best[i];
	}
	if(sum<420)cout<<-1;
	else {
		for(int i=0;i<6;i++)cout<<id[i]<<" ";
	}
	return 0;
}
```

# 出题需要加法

## 思路
二进制+前缀计数

统计L到R，可以转化为统计0~R和0~L-1，然后两段相减。也可以一开始就预处理所有二进制的树，然后判断L~R中的二进制数。我用的是前者的方法。

看到2可以直接想到二进制

两种情况，一是x==y，二进制中只有1个1，二是x!=y，二进制中有2个1

所以可以用1来移位运算

1LL的意思是long long类型的1

注意，本题的范围很大，要开long long

两个long long相加最坏情况会爆，可以用unsigned long long来存

相加的公式为unsigned long long x=(1LL<<i)+(1LL<<j);

## 代码
```c++
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
int calc(ll n){
	if(n<0)return 0;
	int cnt=0;
	for(int i=0;i<=62;i++){
		for(int j=0;j<=i;j++){
			unsigned long long x=(1LL<<i)+(1LL<<j);
			if(x<=n)cnt++;
		}
	}
	return cnt;
}
void solve(){
	ll L,R;cin>>L>>R;
	cout<<calc(R)-calc(L-1)<<'\n';
}
int main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int t;cin>>t;
	while(t--)solve();
	return 0;
}
```

# 出题需要构造

## 题意

构造一个n*m的表，每个格子可以写上1~n

选一个k（可以自己挑），从1~n中，随便挑k个数字，把表中的这些数字点亮

要求：无论怎么选k种数字，确保表每行/每列要有2个点亮的格子

## 思路
只有当n==m且n>=2时有解

每行点亮2个，一共n行，共有2n个格子被点亮

每列点亮2个，一共m列，共有2m个格子被点亮

所以2n=2m，即n=m

当n=1时，无法在每行/列点亮2个格子

有解时，直接选定k=2，因此只要构造每行/列每个数字只出现一次的表

例如：
2 1 3
3 2 1
1 3 2

如何构造？

直接记住函数
```c++
for(int i=0;i<n;i++){
	for(int j=0;j<n;j++){
		cout<<(i+j)%n+1<<" ";
	}
	cout<<'\n';
}
```
可以自己模拟一下

## 代码
```c++
#include<bits/stdc++.h>
using namespace std;
void solve(){
	int n,m;
	cin>>n>>m;
	if(n!=m||n==1)cout<<"NO"<<'\n';
	else {
		cout<<"YES"<<'\n'<<2<<'\n';
		for(int i=0;i<n;i++){
			for(int j=0;j<n;j++){
				cout<<(i+j)%n+1<<" ";
			}
			cout<<'\n';
		}
	}
}
int main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int t;cin>>t;
	while(t--)solve();
	return 0;
}
```
